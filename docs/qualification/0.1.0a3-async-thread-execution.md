## Authority model

The qualification preserves:

```text
RuntimeKernel
=
Run lifecycle authority

Runner
=
progression / orchestration

Executor
=
execution mechanism

ExecutionContext
=
explicit attempt context

ContextVar
=
ambient execution-local context
```

Async and Thread executors therefore extend the execution mechanism without taking ownership of Run lifecycle law.

## Capacity model

### AsyncExecutor

```text
max_concurrency
        │
        ▼
BoundedSemaphore
        │
        ▼
Task creation / execution
```

A capacity slot is released on success, ordinary failure or cancellation.

### ThreadExecutor

```text
max_in_flight
        │
        ▼
capacity gate
        │
        ▼
ThreadPoolExecutor submission
```

`max_in_flight` is distinct from `max_workers`.

If an asyncio await is cancelled while the underlying thread keeps running, the capacity slot remains occupied until the backend Future actually completes.

## Cancellation boundary

The milestone intentionally distinguishes control-flow cancellation from hard execution termination.

### Async

```text
CancelledError
=
propagated control signal
```

### Thread

```text
cancel await
!=
terminate Python thread
```

No hard thread cancellation guarantee is claimed.

## Deferred semantics

This qualification does **not** claim:

- ProcessExecutor;
- SubprocessExecutor;
- timeout semantics;
- deadline semantics;
- hard thread cancellation;
- durable RunStore;
- workers;
- leases;
- fencing tokens;
- distributed ownership;
- retry/recovery runtime;
- checkpoint/resume;
- effects/outbox;
- remote execution;
- sandboxing;
- public AsyncRuntime;
- public ThreadRuntime.

Absence is deliberate.

## Release boundary

A successful qualification means:

> PyRuntimeKit 0.1.0a3 provides a coherent local concurrent execution layer across Inline, Async and Thread backends, with explicit context propagation, bounded local capacity, backpressure, normalized failures, truthful cancellation semantics, explicit thread-pool cleanup and preserved lifecycle authority boundaries.

It does **not** mean that PyRuntimeKit is durable, process-isolated, distributed, remotely executable or equipped with timeout/deadline policy.
