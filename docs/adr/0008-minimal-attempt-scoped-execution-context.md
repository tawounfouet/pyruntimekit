# ADR 0008 — Keep the initial ExecutionContext minimal and attempt-scoped\n\n- **Status:** Accepted\n- **Date:** 2026-10-25\n\n## Context\n\nThe target context model eventually includes worker ownership, deadlines, cancellation, leases, fencing and propagation concerns. PR 14 belongs to the first local Runtime milestone, before those concepts have their own implementations.\n\n## Decision\n\nIntroduce a top-level `pyruntimekit.contexts.ExecutionContext` that models only the information required to identify and correlate one concrete execution attempt:\n\n```text\nrun_id\nworkload_id\nattempt\ncorrelation_id\ntrace_id?\nmetadata\n```\n\nThe context is a frozen, slotted dataclass. Its operational identity is `(RunId, AttemptNumber)`.\n\n`correlation_id` is required non-empty text because the bootstrap contract includes it as an initial field. `trace_id` is optional and normalized when present.\n\nMetadata is restricted to JSON-compatible values and copied into the existing defensive immutable mapping representation.\n\n## Dependency boundary\n\n`contexts/` may depend on stdlib and domain value types only in this milestone.\n\nIt must not depend on RuntimeKernel, application services, API facades, executors, stores or infrastructure SDKs.\n\n## Deferred concepts\n\nThe following target-context capabilities are intentionally deferred until their owning milestones:\n\n- worker assignment and WorkerId;\n- parent Run relationships;\n- deadline / timeout;\n- cooperative cancellation token;\n- lease, fencing and ownership context;\n- ContextVar propagation;\n- RuntimeContext services such as stores, clock, registries or observability.\n\n## Consequences\n\n- a retry produces a new ExecutionContext because AttemptNumber changes;\n- Run remains the lifecycle source of truth;\n- ExecutionContext remains a transportable operational view rather than a service locator;\n- Runner and Executor can later share this object without creating a dependency cycle;\n- distributed ownership semantics are not implied by this first context model.\n
